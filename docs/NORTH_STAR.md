# ferret — North Star

★ **ferret measures Claude Code sessions in bytes — the multi-step sequences worth one deterministic helper, the calls that bought nothing, who burned it — and proves each fix by the delta.**

### Measures of success

- burn spent on multi-step routines decreases as they become helpers;
- the share of fixes with a measured before/after rises;
- bytes lost to misfires and polling decrease;
- burn is attributed to the agent that spent it, parent and subagent apart;
- the ferret calls an agent needs to answer one question decrease.
